# Anarres Homebrew tap

This is the official Homebrew tap for the
[Anarres](https://github.com/anarres-organization/anarres) command-line
interface.

## Install

```bash
brew install anarres-organization/tap/anarres
```

## Upgrade

```bash
brew upgrade anarres
```

## Uninstall

```bash
brew uninstall anarres
```

Release artifacts and checksums are published in the
[Anarres releases](https://github.com/anarres-organization/anarres/releases).
